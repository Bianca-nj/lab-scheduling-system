**Rule-Based Intelligent Laboratory Scheduling System**
A Laravel-based web application that automates laboratory scheduling through predefined rules. The system evaluates laboratory requests, checks resource availability, detects scheduling conflicts, and allocates suitable laboratories based on defined scheduling criteria.

**Project Overview**
The Rule-Based Intelligent Laboratory Scheduling System is designed to simplify laboratory booking and reduce the manual effort involved in managing laboratory schedules.
Lecturers can submit laboratory booking requests through a public request form. The system processes each request using predefined rules and automatically determines whether the request can be approved or rejected.

**Features**
Laboratory Scheduling: Submit requests for laboratory sessions.
Automatic Allocation: Assign suitable laboratories based on scheduling rules.
Capacity Validation: Check whether a laboratory can accommodate the requested class size.
Conflict Detection: Identify scheduling conflicts and unavailable time slots.
Resource Management: Manage laboratory equipment and other available resources.
Rule Management: Configure the rules used when evaluating scheduling requests.
Automatic Decisions: Approve or reject requests based on availability and scheduling criteria.
Alternative Suggestions: Provide alternative scheduling or resource suggestions when the requested arrangements are unavailable.
Administrative Dashboard: Manage laboratories, resources, schedules, rules, and system settings.
